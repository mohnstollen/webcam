# Startliste der Webcams – einmalig importieren mit:
#   sudo -u www-data php webcam-cli.php import webcams.txt
# Danach werden die Webcams in der Verwaltung (admin.php) gepflegt.
#
# Format (durch Leerzeichen/Tabs getrennt):
#   name   quelle   Anzeigetitel (optional, darf Leerzeichen enthalten)
#
# name    → Dateiname ohne Endung: nur a-z, 0-9, "-" und "_" (keine Umlaute).
#           Die Endung (.jpg/.png/…) wird anhand des Bildinhalts gesetzt.
# quelle  → URL eines Bildes, oder mit Präfix:
#             html:URL   Webseite laden und das erste Webcam-JPG darin verwenden
#             mjpeg:URL  ein Einzelbild aus einem MJPEG-Videostream holen (ffmpeg)
#           Platzhalter in der URL: {utc:FORMAT} bzw. {lokal:FORMAT} werden mit
#           `date +FORMAT` ersetzt, z. B. {utc:%H} → aktuelle UTC-Stunde.
#
# Zeilen mit # am Anfang sind Kommentare. Zum Deaktivieren einfach auskommentieren.
#
# feratel-XXXX: Standort ist aus der URL nicht ersichtlich – bei Bedarf umbenennen.
